# Фоновая музыка

Распакуй архив обновления и загрузи его содержимое в 3D.MyLove, сохранив папки src, scripts и tests. Подтверди замену совпадающих файлов. index.html, фотографии и описания обновление не меняет.

Музыкальный файл должен лежать в ЭТОМ ЖЕ репозитории: рядом с index.html или внутри папки music. Если музыка пока только в старом for-liza, загрузи выбранный файл и в 3D.MyLove. Сам ZIP на GitHub загружать не нужно.

Можно назвать файл music.mp3. Поддерживается автоматический поиск MP3, M4A, AAC, OGG, WAV, FLAC и WEBM; возможность воспроизведения зависит от кодека и браузера. Для совместимости с телефонами лучше MP3.

При нескольких файлах порядок выбора: music.mp3 в корне, затем music/music.mp3, затем первый по имени трек в music, затем первый трек в корне. Имена с пробелами и русскими буквами поддерживаются. Другие папки и вложенные подпапки не сканируются.

После Commit changes дождись зелёной отметки в Actions и обнови страницу сайта. Скрипт сборки сам найдёт музыку, скопирует её в публикуемый сайт и создаст music-manifest.json. Этот JSON вручную менять не нужно. Чтобы заменить песню, замени выбранный файл и дождись следующей публикации.

Музыка зациклена. Начальная громкость — 40% (на некоторых телефонах громкость регулируется только кнопками устройства). Сайт пытается включить музыку сразу при открытии, как только загрузится список музыки. Кнопка управления доступна во вступлении и на основной странице. В открытой фотографии есть отдельная кнопка управления той же музыкой.

Если браузер разрешает автоматический звук, музыка начинается без нажатий. Если запрещает (часто при первом посещении и на телефонах), сайт показывает подсказку и повторяет попытку при первом нажатии на страницу или клавишу. Гарантировать звук без действия пользователя во всех браузерах невозможно. Если нажать до загрузки списка музыки, может понадобиться ещё одно нажатие. После ручной паузы другие нажатия и повторное вступление не включают звук самовольно. Увеличение круга, просмотр фото и переход между ними не прерывают трек.

Если музыкального файла нет, кнопка скрыта, остальные части сайта продолжают работать. Если файл повреждён или звук запрещён браузером, плеер сообщает об ошибке и позволяет повторить попытку.

Локальная проверка: node server.mjs. Проверка публикации: node scripts/build-pages.mjs. Новый музыкальный файл появляется после перезагрузки страницы локально, а на GitHub Pages — после новой сборки.
