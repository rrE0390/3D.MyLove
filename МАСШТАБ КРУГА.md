# Приближение всего круга с фотографиями

Распакуйте for-liza-gallery-zoom-update.zip и загрузите содержимое в корень репозитория через Add file → Upload files. Сохраните папку src: внутри неё обновлённый scenes.js и новый gallery-controls.js. Нажмите Commit changes и дождитесь зелёной галочки в Actions.

Под 3D-сценой появится строка «Масштаб круга»:

- «+» приближает сцену к центру нижних передних фоторамок, «−» отдаляет. Сердце больше не является центром приближения.
- Кнопка с процентами возвращает исходный размер 100%.
- Колёсико над 3D-сценой изменяет её масштаб.
- На телефоне разводите два пальца для приближения, сводите для уменьшения.
- Горизонтальное движение одним пальцем или мышью по-прежнему поворачивает круг.
- Вертикальное движение одним пальцем прокручивает страницу.
- После фокусировки сцены клавишей Tab: «+», «−», «0» управляют масштабом, стрелки влево и вправо поворачивают круг.

Масштаб сцены ограничен диапазоном 100–300%. Размер самого окна галереи не меняется, увеличенная сцена остаётся внутри его границ. При изменении размера экрана выбранный масштаб сохраняется. Масштаб открытой отдельной фотографии независим от масштаба круга.

При переходе от 100% к 200% камера плавно меняет направление с общего плана на середину ближайшего нижнего ряда рамок. При 200–300% эта точка находится в центре окна. Вращение кольца не меняет точку приближения; новые фотографии проходят через центр. Сброс к 100% возвращает первоначальный общий вид. Для этой версии также нужен файл src/gallery-camera.js.

Обновление не затрагивает фотографии, TXT-описания, счётчик и настройки публикации.
