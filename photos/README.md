Скопируйте сюда фотографии JPG, JPEG, PNG, WebP, AVIF или GIF. Можно также положить их рядом с index.html.
При запуске node server.mjs список обновляется автоматически: страница проверяет изменения каждые 15 секунд и после возврата на вкладку. Править код не нужно.
Для статического хостинга выполните node scripts/scan-photos.mjs перед публикацией, чтобы обновить photo-manifest.json.
Файлы сортируются по имени: 01.jpg, 02.jpg, 03.jpg… Лучше использовать изображения до 1600 пикселей по длинной стороне.
Вертикальные фотографии в сцене кадрируются по центру. По нажатию открывается полный снимок.
