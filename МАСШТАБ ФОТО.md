# Приближение фотографий

Распакуйте for-liza-photo-zoom-update.zip и загрузите его содержимое в корень репозитория через Add file → Upload files, сохраняя папку src. Важно загрузить и новый файл src/photo-viewer.js. Нажмите Commit changes и дождитесь успешной публикации в Actions.

Откройте любую фотографию:

- «+» приближает, «−» уменьшает. Кнопка с процентом возвращает 100%.
- Колёсико мыши над снимком приближает к точке под курсором. Жест масштабирования на трекпаде также поддерживается через события колёсика.
- На телефоне разводите или сводите два пальца над снимком.
- Увеличенную фотографию можно перетаскивать мышью или одним пальцем.
- Двойной щелчок или двойное касание переключает между 100% и 250%.
- С клавиатуры: «+», «−», «0». При увеличении стрелки перемещают изображение; при 100% стрелки влево и вправо переключают фотографии. Escape закрывает просмотр.

Масштаб ограничен диапазоном 100–500%. При смене фотографии он сбрасывается. На исходном масштабе один палец над фото прокручивает окно с описанием. За пределами фото сохраняется обычная прокрутка.

Фотографии и TXT-описания сохраняются, их повторно загружать не нужно. Обновление не меняет дату, текст страницы и настройки GitHub Actions.
