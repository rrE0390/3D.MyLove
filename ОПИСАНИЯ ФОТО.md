# Название и описание для каждой фотографии

## Один раз обновить сайт

В архиве for-liza-descriptions-update.zip находятся папки scripts и src и файл styles.css. Распакуйте архив и перетащите эти папки целиком вместе с styles.css в корень репозитория через Add file → Upload files. Сохраните Commit changes. Папки должны сохранить свои имена. Существующие фото и настройки публикации менять не нужно.

## Добавить текст прямо на GitHub

1. Откройте папку photos и найдите нужный снимок по миниатюре или имени.
2. Нажмите Add file → Create new file.
3. Для IMG_20260910_032152.jpg создайте рядом IMG_20260910_032152.txt. Полный путь получится photos/IMG_20260910_032152.txt. Если photos/ уже показано слева, введите только имя файла.
4. В первой строке напишите название момента. Со второй строки — описание. Между абзацами можно оставлять пустые строки. Форматирование Markdown и HTML не требуется: текст отображается как написан.
5. Нажмите Commit changes и дождитесь зелёной галочки во вкладке Actions.

Пример текста (замените своим):

    Наш вечер у моря

    Здесь напиши, что ты чувствуешь, когда смотришь на этот снимок.

    Здесь можно добавить ещё одно воспоминание или пожелание.

Название появится вместо «Наш момент 01», а описание — ниже. Если TXT отсутствует, останется прежняя подпись. Чтобы изменить описание, откройте TXT на GitHub и нажмите карандаш. Чтобы убрать описание, удалите TXT или оставьте в нём только первую строку.

Такой же способ работает для снимков рядом с index.html: TXT должен находиться рядом с соответствующей фотографией. Для 01.png описание хранится в 01.txt. Не давайте разным фотографиям в одной папке одинаковое имя без расширения, если у них должны быть разные подписи.

TXT не создаёт дополнительную плитку. Подпись привязана к имени снимка, поэтому при добавлении других фотографий не переедет к чужой карточке. При переименовании фото переименуйте и его TXT.

Если создаёте TXT в Блокноте, сохраняйте в UTF-8. Самостоятельно редактировать photo-manifest.json не нужно: GitHub Actions включает подписи в список автоматически при публикации.
