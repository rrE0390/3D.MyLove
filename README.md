# Для Лизы

Для загрузки на GitHub см. «НАЧНИ ЗДЕСЬ.md». В архив включён процесс GitHub Actions: после каждого изменения в main/master он находит фотографии и публикует сайт. Один раз выберите GitHub Actions в Settings → Pages.

Локальная первая версия: голубое сердце из частиц → календарный счётчик → объёмная круговая фотогалерея с розовым сердцем в центре.

Запуск: `node server.mjs`, затем открыть http://127.0.0.1:4173. Зависимости устанавливать не нужно. Нужен Node.js 18 или новее. Файлы также можно разместить на обычном статическом хостинге, включая GitHub Pages. Открывать через сервер, не через file://.

Дата начала: 13 февраля 2026, 23:46:22, UTC+8 (Asia/Irkutsk). Время сохранено из прежнего сайта, пояс зафиксирован согласно обсуждению. Месяцы календарные, дни — остаток после полных месяцев. Счётчик использует часы устройства.

## Фотографии

Положите снимки рядом с `index.html` или в `photos/`. Поддерживаются JPG, JPEG, PNG, WebP, AVIF, GIF (в 3D-сцене GIF статичен). Локальный сервер обнаруживает снимки автоматически: страница проверяет список каждые 15 секунд и при возврате на вкладку. Количество карточек равно количеству файлов, пустых плиток нет. Имена сортируются естественно: 1.jpg, 2.jpg, 10.jpg. В галерее снимок кадрируется; при нажатии показывается целиком. Более 16 фото распределяются по нескольким круговым уровням; камера учитывает их высоту.

Для статического хостинга перед публикацией запустите `node scripts/scan-photos.mjs` (или `npm run build`) и загрузите обновлённый `photo-manifest.json` вместе с фотографиями. На статическом хостинге браузер не может сам перечислить файлы каталога, поэтому список формируется на этом шаге. При добавлении или удалении фото повторите команду. Локальному серверу отдельная сборка списка не нужна.

## Управление и адаптация

Сцену можно вращать горизонтальным жестом или мышью; вертикальный жест оставлен для прокрутки страницы. Есть кнопки поворота и паузы. Escape закрывает фото. При включённом уменьшении движения вступление пропускается, галерея изначально неподвижна. Если WebGL недоступен, остаётся обычная прокручиваемая фотогалерея. Рендер приостанавливается вне экрана и на скрытой вкладке. Масштаб камеры подбирается под обе стороны области просмотра.

Three.js 0.180.0 поставляется локально в `vendor/`; лицензия — `vendor/THREE-LICENSE.txt`. Внешних запросов для шрифтов, изображений и скриптов нет. Музыка из прежнего проекта пока не добавлена: это отдельный этап.

Проверка расчёта времени: `node --test tests/*.test.mjs`.

Проверено в Chromium: ширины 320, 390, 768, 844 и 1440 px, мобильная вертикальная прокрутка поверх сцены, повтор вступления, просмотр фото и закрытие Escape, пауза, 0/1/3/8/24 снимка, обновление списка и режим без WebGL. Эмуляция размеров не заменяет проверку на конкретном физическом телефоне.
