# Как загрузить сайт на GitHub

1. Распакуй ZIP-архив на компьютере.
2. Открой свой репозиторий GitHub, например rrE0390/for-liza. Загружай в ветку main (также поддерживается master).
3. В Settings → Pages → Build and deployment → Source выбери GitHub Actions.
4. Через Add file → Upload files загрузи содержимое распакованного архива в корень репозитория. index.html должен находиться сразу в корне, а не во вложенной папке. Сам ZIP загружать не нужно.
5. Обязательно загрузи папку .github вместе с остальными папками! Внутри неё — workflows/pages.yml. Если папка не попала в загрузку, создай через Add file → Create new file файл .github/workflows/pages.yml и скопируй в него содержимое одноимённого файла из архива.
6. Нажми Commit changes. Во вкладке Actions появится запуск Publish site for Liza. Дождись зелёной галочки. Если запуск не появился, открой этот процесс в Actions и нажми Run workflow.
7. Ссылка на готовый сайт появится в Settings → Pages.

Если загружаешь в прежний репозиторий, новая версия заменит его index.html. История GitHub сохранит предыдущую версию. Если там уже есть другой процесс публикации Pages, оставь один нужный процесс, чтобы две версии не перезаписывали друг друга.

## Добавление фотографий

Загрузи JPG, JPEG, PNG, WebP, AVIF или GIF в photos/ либо рядом с index.html и сделай Commit changes. GitHub автоматически пересоберёт список: сколько файлов — столько плиток. Код менять не нужно. Аналогично при удалении фотографий.

Для порядка назови фотографии 01.jpg, 02.jpg, 03.jpg. Настоящих снимков в архиве пока нет, поэтому сначала в галерее будет только сердце.

## Локальный просмотр

Открой терминал в распакованной папке и запусти node server.mjs. Затем открой http://127.0.0.1:4173. Нужен Node.js 18 или новее. Обычный двойной щелчок по index.html не запустит модульные скрипты: используй сервер или GitHub Pages.

Локально фото добавляются автоматически в течение 15 секунд. Для другого статического хостинга выполни node scripts/build-pages.mjs и загрузи содержимое созданной папки _site.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
